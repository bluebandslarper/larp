# LARP Wallet

A fictional wallet simulator for roleplay. No real money, bank connections, or payment processing is involved. Simulated transactions and receipts are not proof of payment.

## Setup

1. Upload `index.html` and `README.md` to the root of your GitHub repository.
2. In Settings > Pages, select Deploy from a branch, main, and /(root).
3. Open the published website. On iPhone, use Safari's Add to Home Screen option.

## Storage

Wallet settings and transactions are stored locally in the browser. Clearing website data may erase them.

## Home Screen icon
Upload apple-touch-icon.png alongside index.html. Replace it with your own 180 × 180 PNG using the same filename. Open the site in Safari and choose Add to Home Screen.
